- 🧠 **AI-Powered Interview Assistant**: Built with Firebase and Vapi — generates, stores, and manages mock interview conversations.
- 📚 **Student Management System**: A Jakarta EE CRUD web app with pagination, filtering, and i18n support (English, French, Spanish).
- 🗳️ **Secure Voting Platform**: Online election system with real-time result updates using PHP and AJAX and robust user authentication.

## 🌱 Currently Learning
- **Building Scalable Pipelines:** Moving from monolithic data scripts to distributed systems that handle data at scale.
- **Designing Analytics-Ready Data:** Learning how to model data (Star/Snowflake) so it’s actually useful for BI and ML, not just stored.
- **Mastering Real-time vs. Batch:** Exploring the trade-offs between processing data the second it arrives versus in high-volume chunks.
- **Data Quality & Reliability:** Figuring out how to automate cleaning and validation so the "garbage in, garbage out" rule doesn't ruin the ML models.
- **Operationalizing ML:** Bridging the gap between a local notebook and a production pipeline that feeds features to a model.
- **System Orchestration:** Working on ways to chain complex tasks together so they recover gracefully when a step fails.
